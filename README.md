# Projeto Android

Página web responsiva sobre a origem e a evolução do mascote do sistema operacional Android. O projeto apresenta a história do **Bugdroid**, suas primeiras versões e algumas curiosidades sobre os nomes das versões do Android.

Este projeto foi desenvolvido como atividade prática do **capítulo 17 do curso de HTML e CSS do Curso em Vídeo**, com foco na criação de páginas estruturadas, estilização com CSS, uso de imagens, fontes personalizadas e adaptação para diferentes tamanhos de tela.

## Acesse o projeto

A página está disponível no GitHub Pages:

[Visualizar o Projeto Android](https://rafaelrodriguesmagdaleno.github.io/Projeto_Android/)

## Sobre a página

O conteúdo aborda:

- A origem do sistema operacional Android;
- A primeira versão do mascote;
- A criação do Bugdroid pela designer Irina Blok;
- A evolução visual do mascote;
- A tradição de nomear versões do Android com nomes de doces;
- A mudança para a numeração a partir do Android 10.

## Tecnologias utilizadas

- **HTML5** para a estrutura semântica da página;
- **CSS3** para estilização, cores, tipografia e layout responsivo;
- **GitHub Pages** para hospedagem do projeto;
- Fonte personalizada `idroid.otf` para complementar a identidade visual;
- Imagens e recursos visuais relacionados ao Android.

### Principais arquivos

- `index.html`: contém o conteúdo e a estrutura principal da página;
- `estilo/style.css`: reúne as regras visuais e os ajustes de responsividade;
- `fontes/idroid.otf`: fonte personalizada utilizada no projeto;
- `imagens/`: armazena as ilustrações, fotografias e o favicon da página;
- `LICENSE`: define os termos de licença do projeto.

## Como executar localmente

Não é necessário instalar dependências ou utilizar um servidor para visualizar a página. Basta clonar o repositório ou baixar os arquivos e abrir o `index.html` no navegador.

### Clonando o repositório

```bash
git clone https://github.com/RafaelRodriguesMagdaleno/Projeto_Android.git
cd Projeto_Android
```

Depois, abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão **Live Server** no Visual Studio Code para executar o projeto durante o desenvolvimento.
